## 设备&环境

树莓派 5

Linux M0 6.18.34+rpt-rpi-2712 #1 SMP PREEMPT Debian 1:6.18.34-1+rpt1 (2026-06-09) aarch64

## 需求点

经过几次讨论迭代，我们最终决定将方向转变为**基于树莓派，agent的物联网平台**

简单来说就是将树莓派装上agent，利用远程操控能力对直接对agent下达命令，再来由agent的mcp对物理操控

## 目前想到的难点

寝室在工作日每天晚上会断电断网，如何持续运行？

如果要通过校园网访问，断网之后每次需要重新认证账号？

校园网账号数量不够！我寝室的电脑需要一个校园网认证账号，外面的携带的笔记本需要一个认证账号，但是我校园卡+校园网只有两个账号，如果再加上树莓派就没有网络认证账号了

## 解决方案

目前思考的方案是让树莓派充当寝室里的常在线远程管理节点 / 跳板机 / WoL 控制器

树莓派需要承担的指责如下：

- **远程进入寝室内网**
- 作为agent的载体
- 操控物理设备


## 分工

分工如下：

1. 用户操作的界面，可以是app，也可以是任何形式
2. `VPS`与树莓派的通信连接
3. 树莓派上的`agent`，主要功能只有操作物理设备的mcp
4. 树莓派与物理设备的连接，适配
