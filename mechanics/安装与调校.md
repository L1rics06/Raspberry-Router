# 如何让一个舵机按上下翘板开关

软件已实现，当前改为SG90微型9g舵机，实际墙面尺寸和安装孔位只能现场测量。本方案采用双臂舵盘，两个方向分别压上下端

## 推荐姿态

舵机输出轴保持**水平，并且平行于墙面**，不是朝墙垂直伸出

双臂舵盘在home时竖直，上臂靠近开关上端，下臂靠近开关下端，两个接触点都与面板留出间隙

```text
正面看墙：

       上端按压区
           ●  ← 双臂舵盘上端的软接触点
           │
           O════[ 舵机本体 ]  ← 输出轴水平且平行墙面
           │
           ●  ← 双臂舵盘下端的软接触点
       下端按压区

O为摆臂旋转中心，●与开关面之间在home时均有间隙
```

绕这个水平轴旋转时，一个方向使上臂向墙移动、下臂离墙；反向则下臂向墙、上臂离墙，所以能分别压两端

若输出轴垂直朝墙，普通平面舵盘会在面板平面内转动，通常无法直接产生按压方向位移，不能只照着“舵盘转了”就算安装正确

## 支架需要满足什么

- 独立固定舵机本体，预留前后和上下调整空间，线材不承力
- 双臂孔位应对准开关上下两块按压区域，不能压在中间转轴附近
- 摆臂末端可加薄软垫，取刚能稳定切换的行程，不持续深压面板
- home时仍能手动按开关，遇卡住可先stop并及时切断供电
- 只在面板外侧安装，不拆市电端子或把支架螺丝打入未知墙内线路位置

可先用纸板或临时夹具验证几何，再做牢固支架；最终孔距按实物舵机耳孔测量，不使用手册其他型号的外形表代填

## 行程估算

设摆臂旋转中心到接触点的长度为L，home时离开关的间隙为g，开关实际需要按下距离为s

粗略按压角度为 `θ = asin((g+s)/L)`；这是刚性、初始竖直摆臂的几何估算，实际还受软垫、开关形状和安装偏差影响

**仅举例，不作为你的标定值**：L=15mm、g=1mm、s=1.5mm，则θ约9.6度。SG90实际脉宽与角度范围因型号/批次不同，不将这个角度换算成固定us；从1500us附近每次10us试探

软件初始窗口1400～1600us即中位附近±100us，保护范围1000～2000us；不保证某窗口必然按到开关，实际用home/on/off记录

SG90的9g是质量，不能当成扭矩。其输出能力远小于原20kg方案；若力不够，缩短摆臂可增加接触力，但会减少行程，必须重新核对间隙。持续压不动应停止，不通过扩大脉宽或堵转硬压

## 实际调校顺序

1. 脱离开关，执行1500us空载中位命令
2. 切断舵机电源，在不强扳输出轴的前提下调整舵盘安装方向，使双臂接近竖直
3. 固定舵机和支架，确认回中时上下端都不接触面板
4. 接通电源，再小步靠近上端，确认切换后立即退回
5. 标定另一方向，同样只取刚能稳定切换的位置
6. 记录home/on/off，测试单轮，再连续10轮观察

哪个端是开、哪个端是关以现场灯光观察为准，程序不把“脉宽变大”固定解释为开灯

如果没有双臂舵盘，也可使用单臂加机械连杆实现双向按压，但需要另行验证其几何与间隙；本包算法仍使用三个现场标定位置

## 不合适时如何处理

摆臂够不到：先调整本体与墙面的距离和接触点长度，再考虑小幅扩大脉宽窗口

一边能压、另一边够不到：检查旋转中心、上下位置和双臂是否对称，不能单靠加大扭力解决

回中仍顶着：重新调整舵盘齿位或home，不把持续顶压当成保持开关状态

灯状态取决于另一处双控开关：固定按上/下端不能可靠表达开和关，暂停该目标，改用反馈方案或与项目负责人确认控制逻辑
