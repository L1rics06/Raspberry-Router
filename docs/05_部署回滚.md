# 部署、自启动和恢复

## 两个服务

| 服务 | 作用 |
|---|---|
| maker-servo-pwm-prepare.service | 开机找到RP1 PWM0，导出通道0，设置20ms周期和权限，保持PWM禁用 |
| piagent-task4.service | 执行静态预检，运行修复版Agent，由Agent启动墙灯MCP |

Pi准备脚本需要root修改config.txt和sysfs权限；实际Agent使用正常登录账号，不以root运行

## 首次启用PWM

```bash
bash scripts/setup_pi.sh
bash scripts/servo.sh init
sudo bash scripts/enable_pi5_pwm.sh "$(id -un)"
```

脚本备份原config.txt，添加BCM12硬件PWM overlay，安装准备服务并把账号加入gpio组

接线调整在Pi关闭并断开USB-C电源后进行；启用PWM后重启Pi，重新登录使组权限生效，再执行servo doctor。若已有其他PWM overlay，脚本拒绝抢占，应先明确其用途

准备脚本只操作地址含98000的RP1 PWM0，不使用9c000风扇PWM；不占Pi5专用风扇接口

## 先本地标定，后生成Agent

详见使用步骤，完成电气记录和机构标定后，在hardware.local.toml填真实URL与设备ID

设备令牌通过TASK4_DEVICE_TOKEN环境变量读取，再运行prepare-agent。生成的私有配置在.runtime/generated，700目录、600配置权限，不进入交付ZIP

服务通过PIAGENT_CONFIG环境变量读配置，上游没有--config启动选项。生成文件已存在时拒绝覆盖，可用--output指定新目录

服务依赖PWM准备服务，启动前检查Pi5、标定、供电记录、配置一致性；退出后还有ExecStopPost补充清理PWM，处理进程被终止时硬件PWM可能继续输出的情况

## 常用管理

```bash
bash scripts/service.sh install
bash scripts/service.sh start
bash scripts/service.sh status
bash scripts/service.sh logs
bash scripts/service.sh stop
```

install只安装，start才立即启动并启用开机自启；stop会停止并取消自启，下一次start会重新启用

已有piagent-agent或piagent服务运行时脚本拒绝启动新Agent，自定义服务名和手动Python进程仍需现场检查；不要批量杀死所有Python

```bash
systemctl list-units --type=service --all 'piagent*'
pgrep -af 'pi_agent|wall_light|all_devices'
```

## 紧急停止和恢复

```bash
bash scripts/servo.sh stop
```

停止命令把全机停止标记置为1并禁用PWM，运行中的驱动不能重新使能。SG90停止PWM不一定完全卸力，卡住时及时切断供电，断电后再调整接线

恢复时先停止Agent/MCP，检查并移开机构，再清除标记：

```bash
bash scripts/service.sh stop
bash scripts/servo.sh reset-stop
bash scripts/servo.sh doctor
bash scripts/service.sh start
```

reset-stop只清标记，不发送脉冲；控制器仍持有全机锁时拒绝清除。首次上电或恢复后不自动按灯

## 重启与离线检查

现场观察stop/start后设备能重新上线且没有误按开关；浏览器在设备离线时应明确失败，恢复后不自动补发积压按压

服务停止只能验证设备离线处理，真实网络断开与恢复需要另做现场测试；只要没做就不能在证据记录中勾选完成

## 撤回部署

```bash
bash scripts/service.sh stop
bash scripts/service.sh uninstall
sudo systemctl disable --now maker-servo-pwm-prepare.service
```

以上只处理本包服务，保留私有配置和上游原项目。若不用硬件PWM，在确认没有其他用途后，从config.txt中删除本包增加的 `dtoverlay=pwm,pin=12,func=4`，再重启

不自动把整个config.txt回滚为旧备份，以免覆盖之后的其他系统设置

## 再打包

Windows运行 `.venv\Scripts\python.exe scripts\build_release.py`

交付ZIP保存到创客父目录，排除本机venv、运行数据、真实.local/.private配置、日志和现场视频，包含可移植源码、模板、手册参考和脱敏软件报告
