# 上游现状与本包补齐内容

2026-11-04再次核对，上游HEAD仍为 [f9c64f01](https://github.com/L1rics06/Raspberry-Router/commit/f9c64f01b4d3d421e862b3acd75f90ac49a44684)

| 固定上游存在的问题 | 本包的处理 |
|---|---|
| 设备服务只有LED、风扇、继电器、温湿度、状态5个工具，没有实际舵机/墙灯工具 | 新增Pi5硬件PWM和light.set，合并入口保留原5个工具 |
| README中的SG90描述与实际源码不一致 | 上游正式设备服务仍无舵机工具；本包已独立实现SG90、5V控制 |
| 先前计划的BCM17与原LED默认脚冲突 | 舵机固定改到BCM12物理32脚，硬件PWM通道0 |
| Agent把设备内层ok=false包装成外层ok=true | runtime_source/agent修复内外层错误及MCP isError传播 |
| 聊天可能在工具失败后仍继续由模型宣称成功 | 运行版Agent遇工具失败立即返回，不再请求模型掩盖错误 |
| 多个MCP的devices.status同名会被覆盖 | 运行版拒绝同名，提供单一合并入口 |
| PWM控制器编号随内核变化 | 根据RP1 PWM0的98000地址和compatible查找，不写死pwmchip0/2 |

## 源码位置

原始来源为 [设备服务](https://github.com/L1rics06/Raspberry-Router/blob/f9c64f01b4d3d421e862b3acd75f90ac49a44684/devices/device_mcp_server.py)、[Agent工具循环](https://github.com/L1rics06/Raspberry-Router/blob/f9c64f01b4d3d421e862b3acd75f90ac49a44684/agent/pi_agent/agent_loop.py)、[MCP池](https://github.com/L1rics06/Raspberry-Router/blob/f9c64f01b4d3d421e862b3acd75f90ac49a44684/agent/pi_agent/mcp_client.py)

upstream_snapshot保存47个运行基线文件，并补齐7个原始文本说明/同步脚本用于集成，54个文本文件的Git对象与上游一致；不含原仓库PDF和PPTX，SOURCE_MANIFEST记录原47个运行文件，INTEGRATION_BASE_MANIFEST记录全部54个文本文件

本包没有推送或修改GitHub远程仓库，当前连接的仓库权限push=false。已提供本地仓库集成源码和完整补丁，Agent两处修复包含在其中；对方分支若已有新改动，先检查补丁冲突，不能覆盖未提交的工作

## 尚需现场确认

本次没有实体Pi5和舵机，未验证ARM安装、systemd真正启动、实际波形、3.3V输入兼容、供电峰值、安装尺寸、三个位置、开关亮灭、公网代理及真实模型
