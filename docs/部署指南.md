# PiAgent 部署指南（VPS + 树莓派）

> 分工 B/C 交付的运维手册。**VPS 侧已部署完成并验收通过**（2026-10-26），本文同时记录现状与复现步骤。

## 1. VPS 网关（分工2）——已部署 ✅

**现状快照**

| 项 | 值 |
| --- | --- |
| 服务器 | 阿里云 Debian 13（地址与登录方式见团队群，勿写入公开文档） |
| 代码位置 | `/opt/piagent/server`（venv: `.venv/`） |
| 服务 | systemd `piagent-server`（开机自启，崩溃自动拉起） |
| 监听 | `0.0.0.0:8000`（uvicorn） |
| 对外入口 | `http://<VPS地址>/piagent`（经 nginx 反代；8000 端口被安全组拦截，未另放行） |
| 数据 | `/opt/piagent/server/data/piagent.db`（SQLite：用户/设备/审计） |
| LLM 代理 | **未配置 Key**（`llm_proxy: not_configured`），Agent 暂用 mock 模式 |

**常用运维命令**

```bash
systemctl status piagent-server          # 状态
journalctl -u piagent-server -f          # 日志
systemctl restart piagent-server         # 重启
cd /opt/piagent/server && .venv/bin/python manage.py add-user <名> <密码>
cd /opt/piagent/server && .venv/bin/python manage.py add-device <设备ID> --owner <名>
```

**接入真实 LLM（拿到 OpenAI 兼容 Key 后）**

```bash
vi /opt/piagent/server.env   # 填入三行后保存：
# PIAGENT_LLM_BASE_URL=https://api.deepseek.com/v1   （以版本路径结尾）
# PIAGENT_LLM_API_KEY=sk-xxx
# PIAGENT_LLM_MODEL=deepseek-chat
systemctl restart piagent-server
# 然后把 agent/config.toml 的 llm_mode 改为 "proxy" 并重启 agent
```

**nginx 说明**：80 端口与本服务器上其他项目（packhub）共用，PiAgent 挂在 `location ^~ /piagent/`（含 WebSocket 升级头），配置见 `/etc/nginx/sites-enabled/packhub`（改动前有备份 `/etc/nginx/packhub.bak`）。

**从零复现部署**：上传 `server/` → `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt` → `cp piagent-server.service /etc/systemd/system/` → 建用户/设备 → 启动。nginx 部分：`/etc/nginx/conf.d/piagent-map.conf`（Connection upgrade map）+ packhub 站点内的 `/piagent/` location。

## 2. 树莓派 Agent（分工3）

```bash
# ① 依赖（Pi OS bookworm 自带 Python 3.11+）
sudo apt install -y python3-venv
git clone <本仓库> /opt/piagent && cd /opt/piagent/agent
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# ② 配置（token 从 VPS manage.py add-device 获取）
cp config.example.toml config.toml && vi config.toml
#    server_url = "ws://<VPS地址>/piagent"
#    device_id / device_token 填写；llm_mode 视 Key 情况选 proxy/mock
#    [[mcp.servers]] 指向设备 server（真机替换 mock）

# ③ 手动验证
.venv/bin/python -m pi_agent        # 看到"注册成功"即打通

# ④ systemd 守护
sudo cp piagent-agent.service /etc/systemd/system/
sudo systemctl enable --now piagent-agent
journalctl -u piagent-agent -f
```

无树莓派时的联调方式：任何能出网的机器装好 agent 依赖、配置后运行即可（当前 demo 即此形态，设备 `pi-dorm-01` 跑在开发机上）。

## 3. 安全基线

- 设备 token、JWT 密钥、LLM Key 均不入库（`agent/config.toml`、`server/data/`、`server.env` 都已 gitignore）；
- 联调账号仅为演示用，正式演示前用 `manage.py add-user` 建正式账号；
- **建议**：更换 VPS root 密码或改用 SSH key 登录；生产前端上线后收紧网关 CORS；有域名后给 nginx 配 TLS（ws:// → wss://，Agent 的 server_url 相应改 wss://）。
