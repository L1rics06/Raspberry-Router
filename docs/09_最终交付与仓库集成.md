## 原仓库如何合入

当前GitHub连接显示push=false，未推送或修改远程main。代码和补丁已完成本地集成及复验，最后的远程合入由有写权限的仓库负责人执行

在原仓库的干净工作区创建分支；先检查原来是否已有未提交改动，不覆盖队友正在做的工作。下面将补丁路径换成实际位置：

```bash
git status --short
git switch -c task4-sg90
git apply --check /实际路径/分工4_GitHub完整补丁.patch
git apply /实际路径/分工4_GitHub完整补丁.patch
```

该补丁依据上游f9c64f01b4d3d421e862b3acd75f90ac49a44684的54个文本文件生成，逐个核对Git blob；已在全新的同版本文本基线上检查并应用，所有变更文件与集成源码逐字节一致

若原仓库后来有新提交，git apply --check可能提示冲突。此时按差异合并，不强行覆盖。集成副本的本地基线历史不是原仓库完整历史，不直接force-push集成目录

合入后在Windows运行：

```powershell
.\scripts\setup.ps1
.\.venv\Scripts\python.exe scripts/verify.py
```

在Pi/Linux安装同一套依赖后运行：

```bash
bash scripts/setup_pi.sh
.venv/bin/python scripts/verify.py
```

verify全程模拟，不需要接舵机。upstream-audit对保留的旧快照缺light.set给出BLOCKED、未填真机模板被BLOCKED，均为预期门槛检查，不代表新实现缺失

## 分工3：Agent负责人

接收完整补丁中的agent/pi_agent/mcp_client.py和agent_loop.py错误传播修复；设备失败必须返回外层ok=false，聊天故障后停止，不自动补发按压

只选一个MCP入口：

| 场景 | 入口/配置 |
|---|---|
| 只用SG90控制寝室灯 | devices/wall_light_mcp.py；profiles/hardware.example.toml |
| 同时用原LED等外设 | devices/all_devices_mcp.py；profiles/combined-hardware.example.toml |

不能同时拉起两个都提供devices.status的服务。默认只允许light.set与devices.status；合并配置允许全部6个工具，relay.set保留手动confirmed要求

实际Pi先完成本地标定和供电记录，再用prepare-agent生成绝对路径的私有配置及独立服务。独立上机包使用runtime_source/agent，仓库集成版自动使用根目录agent

## 新版E2E如何使用

访问令牌在本机终端私有输入，配置中的设备ID必须明确：

```bash
read -rsp '访问令牌: ' TASK4_ACCESS_TOKEN; echo
export TASK4_ACCESS_TOKEN
.venv/bin/python scripts/e2e_test.py --profile profiles/hardware.local.toml
.venv/bin/python scripts/e2e_test.py --profile profiles/hardware.local.toml --actuate --cycles 1
.venv/bin/python scripts/e2e_test.py --profile profiles/hardware.local.toml --actuate --cycles 10 --chat --report reports/hardware-gateway.json
unset TASK4_ACCESS_TOKEN
```

依次为只读、1轮开关、10轮开关加两条聊天；最后一条至少22次按压，必须现场观察。聊天严格检查方向和执行计数，失败立即停止验收，不自动重发

## 接线后按这个顺序验收

1. 红→物理2脚5V，棕/黑→物理6脚GND，橙/白→物理32脚BCM12，断电操作
2. 安装依赖、初始化、启用PWM并重启，doctor只读检查通过
3. 摆臂离开开关，1500us附近空载小步测试，确认供电稳定
4. 安装外部机构，交互标定home/on/off，确认退回间隙和手动操作空间
5. 本地1轮、稳定后10轮，记录实测供电和标定
6. MCP只读→1轮动作→Agent上线→网关只读→1轮→10轮与聊天
7. 观察停机/重启/离线恢复，无误按或补发，保存视频和现场报告

所有命令、异常处理和预期输出见[完整上机步骤](01_使用步骤.md)。SG90若压不动开关，需要改变实际机构或舵机，软件不能补足机械扭矩
