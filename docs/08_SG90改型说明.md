# 改为SG90、5V供电

1. **当前问题**：之前目标为20kg舵机与独立6V，型号改成SG90微型9g后，旧标定、供电说明和全行程范围不能继续沿用
2. **修改位置**：configs/、handoff/、task4/servo_specs.py、servo_control.py、servo_cli.py、pwm_driver.py、profile.py，以及接线/安装/部署文档
3. **修改方案**：修改前红线接独立6V，程序允许旧型号范围；修改后红线接Pi5物理2脚5V、棕/黑线接物理6脚GND，信号仍为BCM12物理32脚。软件固定当前SG90配置标记与5V，保守保护1000～2000us，初始只开放1400～1600us
4. **整体思路**：不改MCP布尔接口和硬件PWM信号脚，只更换舵机配置；init识别旧型号，先备份配置和记录，再清除旧标定。SG90已经完成的当前标定在重复init时保留。所有写配置操作在真实控制器空闲时进行
5. **修改理由**：SG90端点、力矩与原舵机不同，不能只把供电线改接就沿用旧位置。5V输入记录允许4.8～5.25V，是本项目5V电源验收策略，兼容Pi常见5.1V输入，不是宣称SG90厂商的绝对极限
6. **好处与作用**：三线即可做单只SG90上机测试，无需电池；旧配置不会静默使用，代码、记录、手册和交付ZIP一致。若Pi欠压/重启，可改独立5V供舵机并共地，不并联两个正极
7. **注意事项与验证**：改型阶段新增11项SG90测试，当时共63项；最终收尾补充回归后共86项单元测试通过，原MCP与网关仿真复查。真实供电余量、3.3V输入识别、SG90是否按得动开关仍需上机确认，不能用9g推断电流或扭矩

## 旧包怎么升级

先停止Agent/MCP和本地控制程序，关Pi并断开USB-C，换成SG90并按新三线接法连接，再用新包覆盖源码文件

```bash
bash scripts/servo.sh init
bash scripts/servo.sh doctor
bash scripts/servo.sh pulse --us 1500 --hold 0.5 --actuate
bash scripts/servo.sh calibrate --operator "实际操作人" --actuate
```

旧配置会生成带.before-sg90时间戳的备份，并把calibrated和电气approved恢复为false；重新记录home/on/off，确认退回间隙及实际开关状态后save

如果已完成SG90标定，再次init不覆盖它。已启用BCM12硬件PWM的Pi无需因为换舵机重复改overlay，检查doctor即可

## 新接线

| SG90线 | Pi5针脚 |
|---|---|
| 红色V+ | 物理2脚5V |
| 棕/黑色GND | 物理6脚GND |
| 橙色信号 | 物理32脚＝BCM12 |

5V电源针脚与3.3V GPIO信号不是一个用途。Pi5自身仍由USB-C供电，先单只SG90空载测试，再带开关；如果有欠压、重启、抖动或堵转，先停止，不继续连续按压

备用独立5V时：红线从Pi物理2脚移除，改接外部+5V；棕/黑接外部负极，外部负极再与Pi GND共地，信号仍接32脚
